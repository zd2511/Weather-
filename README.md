# Zapify Weather

A responsive weather dashboard with a navy, gold and white visual identity.

## Features
- Current conditions, apparent temperature, wind, gusts, precipitation probability and UV index
- 24-hour hourly forecast including wind, gusts and rain chance
- 7-day forecast with daily highs/lows and precipitation probability
- Practical activity guidance for gardening, painting/spraying, laundry, running, lawn watering, outdoor work, travel and outdoor comfort
- City search, optional browser geolocation and Celsius/Fahrenheit toggle
- Animated atmospheric background and glass-style navigation
- Responsive layouts for desktop and mobile

## Run
Open `index.html` in a browser. A local web server is recommended for the most reliable browser geolocation support. An internet connection is required for live forecasts and the optional Google Fonts stylesheet.

Forecast data is provided by Open-Meteo. Forecasts are model estimates, not guarantees. This project does not currently provide official severe-weather alerts.

## Project structure
- `index.html` — page structure
- `styles.css` — styling and responsive layout
- `app.js` — forecast fetching and rendering
- `assets/favicon.svg` — Zapify Weather icon
